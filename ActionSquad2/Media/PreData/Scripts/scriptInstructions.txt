GENERALE
--------
* - if first character of a value is * then the value is replaced with the value of the local variable with that name
eg: var1="*local_var1" where local_var1 was set to 16 translates to var1="16"

+ Generates a random number in the global var "varName"
<RAND_INT_GLOBAL var_name="varName" nMin="0" nMax="100" />

+if global var_name equals check_value jumps to goto label named LABEL_NAME
<IF_EQUAL_GLOBAL var_name="varName" check_value="10" goto="LABEL_NAME" />

+if global var_name is lower than check_value jumps to goto label named LABEL_NAME
<IF_LOWER_GLOBAL var_name="varName" check_value="10" goto="LABEL_NAME" />

+ jumps to the first label with that name
<GOTO label="LABEL_NAME" />

+defines a label for GOTO instructions
<LABEL name="LABEL_NAME" />

+ face print in debug window (si cu timestamp?)
<DEBUG_PRINT log="Log value in debug window" />

+ pune scriptul pe pauza pana cand variabila locala a scriptului "waitflag1" ajunge la valoarea respectiva "wait-value"
<WAIT_LOCAL_VAR waitflag1="wait-value" />

+ pune scriptul pe pauza pana cand variabila globala din virtual machine "waitflag1" ajunge la valoarea respectiva "wait-value"
<WAIT_GLOBAL_VAR waitflag1="wait-value" />

+ seteaza variabila locala "var-name" pe valoarea "var-value"
<SET_LOCAL_VAR var-name="var-value" />

+ seteaza variabila globala "var-name" pe valoarea "var-value"
<SET_GLOBAL_VAR var-name="var-value" />

+inmulteste o variabila locala cu un factor si salveaza tot in cea locala (float by default)
<MATH_LOCAL_VAR_MUL var-name="numeVarLocala" factor="3.0" />

+ play sound
<PLAY_SOUND ID="SOUND_NAME" [looping="0/1"] />

+ stop sound
<STOP_SOUND ID="SOUND_NAME" [fadeOut="0/1"] />

<SLEEP_ASYNC duration="5.0" />
Sta in script asincron pe durata data de duration.

nKeepAmmoFromSrc - if set it overwrites the ammo qty from "src" idx to "dest" idx

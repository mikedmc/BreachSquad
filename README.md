#Export Animations from Aseprite
1. File->Export->Export Sprite Sheet
2. Play with the settings until you find a good packing, export layers separately
3. set Item Filename (and maybe Item Tagname):
```
{frame}:{layer}:{tag}:{tagframe}
```
*first layer is the one at the bottom, the most visible one is the last layer*
4. Import files in PixelSpriteEd
